Automatic number plate recognition for Indian vehicles.

An academic project combining plate detection, OCR, Indian registration validation, and a web dashboard for vehicle-log review.

Explore the source code Run locally

How it works

1. Detect

YOLOv8 locates candidate registration plates in camera frames.

2. Read

Image preprocessing and EasyOCR extract text from each plate crop.

3. Validate

Registration text is checked against Indian plate formats, then reviewed in the Flask dashboard.

About this GitHub Pages site

This page is a static project overview. GitHub Pages cannot run the Python/Flask backend, connect to your webcam or iVCam, perform live ANPR, or provide the SQLite API. To use the complete application, follow the local setup instructions in the repository README.
